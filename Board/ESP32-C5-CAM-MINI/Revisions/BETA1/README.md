# ESP32-C5-CAM-MINI-BETA1

## General Information

This development board is the first revision of the ESP32-C5-CAM-MINI series. This board revision was made by EasyEDA.

## Board Preview

![alt text](/Board/ESP32-C5-CAM-MINI/Revisions/BETA1/ESP32-C5-CAM-MINI-BETA1-PCB_SampleImage_3D.png "ESP32-C5-CAM-MINI-BETA1")

### Features

- 2x 1x9 pin header (2.54mm) for GPIO.
- Compatible with the OV3660/OV5640 camera sensors.
- 5V to 3.3V DC-DC buck converter.
- 2.8V LDO Voltage Regulator to AVDD, DOVDD.
- 1.5V LDO Voltage Regulator to DVDD.
- 24MHz Crystal Oscillator to XCLK.
- SD Card slot (pins are also exposed to repurpose them as GPIOs).
- SCCB interface pins (IO1, IO3) are exposed to potentially connect to multiple I2C devices under the same bus, with 2.2kΩ pull-up resistors.
